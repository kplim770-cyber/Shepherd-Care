# 🐑 Shepherd Care Portal (Synago-Inspired)

A modern, mobile-first church management and pastoral care platform built for church leadership, campus shepherds, and fellowship leaders.

## 🌟 Key Features
* **Member Directory:** Real-time member registration, status badges, and fellowship/Bacenta grouping.
* **Services & Attendance:** Quick one-tap attendance tracking across Sunday services, midweek meetings, and fellowship units.
* **Pastoral Care Logs:** Record and review shepherd notes, home visits, and counseling records.
* **Growth Analytics & AI Assistant:** Visual trends, reports, and built-in AI tools for leader follow-ups.

## 🛠️ Built With
* **Frontend:** HTML5, Tailwind CSS, Lucide Icons
* **Backend:** Supabase (PostgreSQL with Realtime & Row Level Security)
* **Hosting:** GitHub Pages
